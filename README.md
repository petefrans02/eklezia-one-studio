Which Mac? Apple menu › About This Mac: “Chip: Apple …” or “Processor: … Intel”.
This repository only hosts the installers (the source code is private). The app tells you when a new version is out.

## First opening on a Mac (until the app is notarized by Apple)
1. Open the `.dmg` and drag **Eklezia One Studio** into **Applications**.
2. Double-click it. macOS says it cannot verify the developer: click **Done** (or **Cancel**).
3. Open **System Settings › Privacy & Security**, scroll down and click **Open Anyway** next to “Eklezia One Studio”, then confirm.

## First opening on Windows (until the app is signed)
1. Run `Eklezia-One-Studio-win-x64.exe`.
2. If Windows shows “Windows protected your PC”, click **More info**, then **Run anyway**.
3. Follow the installer. A shortcut is added to the desktop and the Start menu.

## Première ouverture sur Mac (en attendant la certification Apple)
1. Ouvrez le `.dmg` et glissez **Eklezia One Studio** dans **Applications**.
2. Double-cliquez dessus. macOS indique qu'il ne peut pas vérifier le développeur : cliquez sur **Terminé** (ou **Annuler**).
3. Ouvrez **Réglages Système › Confidentialité et sécurité**, descendez et cliquez sur **Ouvrir quand même** à côté de « Eklezia One Studio », puis confirmez.

## Première ouverture sur Windows (en attendant la signature)
1. Lancez `Eklezia-One-Studio-win-x64.exe`.
2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur **Informations complémentaires**, puis **Exécuter quand même**.
3. Suivez l'installation. Un raccourci est ajouté sur le bureau et dans le menu Démarrer.
