# Eklezia One Studio — Downloads

**Eklezia One Studio** is the live production app of [Eklezia One](https://ekleziaone.com): cameras, sound, scenes,
teleprompter, recording and live streaming to YouTube and Facebook — with one Eklezia One account.

➡️ **Download for Mac:** [Eklezia-One-Studio-mac.dmg](https://github.com/petefrans02/eklezia-one-studio/releases/latest/download/Eklezia-One-Studio-mac.dmg)

This repository only hosts the installers (the source code is private).

## First opening on a Mac (until the app is notarized by Apple)
1. Open the `.dmg` and drag **Eklezia One Studio** into **Applications**.
2. Double-click it. macOS says it cannot verify the developer: click **Done** (or **Cancel**).
3. Open **System Settings › Privacy & Security**, scroll down and click **Open Anyway** next to “Eklezia One Studio”, then confirm.

The app then opens normally every time.

## Première ouverture sur Mac (en attendant la certification Apple)
1. Ouvrez le `.dmg` et glissez **Eklezia One Studio** dans **Applications**.
2. Double-cliquez dessus. macOS indique qu'il ne peut pas vérifier le développeur : cliquez sur **Terminé** (ou **Annuler**).
3. Ouvrez **Réglages Système › Confidentialité et sécurité**, descendez et cliquez sur **Ouvrir quand même** à côté de « Eklezia One Studio », puis confirmez.

Ensuite, l'application s'ouvre normalement.
